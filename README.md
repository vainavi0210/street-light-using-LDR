# street-light-using-LDR# LED Brightness Adjusting Project

## Description
This project is used to adjust the brightness of an LED using a potentiometer.

## Required Components
- LED
- Potentiometer
- Resistor
- Breadboard
- 9V Battery
- Connecting Wires

## Project Setup
The project was assembled on a breadboard using the required components.

![Project Setup](IMG-20260920-WA0003.jpg)

## Procedure
1. Connected the components on the breadboard.
2. Connected the LED with the resistor.
3. Connected the potentiometer to the circuit.
4. Connected the 9V battery.
5. Rotated the potentiometer to adjust the LED brightness.

## Functions
- Adjusts LED brightness.
- Potentiometer controls the voltage/current.
- LED brightness increases or decreases based on the potentiometer position.
